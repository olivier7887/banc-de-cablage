# Banc de câblage

Simulateur de schémas électriques de l’Institut Saint-Roch (Marche-en-Famenne) : câblage, simulation, exemples et défis en trois niveaux.

Créé par Lesenfants Olivier, Dachelet Philippe, Baudson Grégory et Degossly Logan, avec l’aide de Claude.

- Application : https://olivier7887.github.io/banc-de-cablage/
- Installation : bouton « Installer l’app » (Chromebook, Android, Chrome, Edge) ou, sur iPhone et iPad, Safari → Partager → « Sur l’écran d’accueil ».
- Fonctionne hors connexion après une première ouverture.

Les solutions des défis sont chiffrées dans `index.html` ; seul le mode prof les déverrouille.
